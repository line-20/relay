## Notes considered, deliberately not changed

- **`_durable_branch` local-HEAD fallback** (backend note): rejected — falling back to the checkout's *current* branch would make `branch != durable` always false, defeating the topic-branch guard (it would happily commit a checkpoint onto a topic branch, the case-B trap). Kept the conservative `'main'` fallback (now tested); a `master`-default repo with no `set-head` correctly refuses rather than mis-commits.
- **No fetch/rebase before push** (backend note): deliberate — the challenger ruling forbids auto-rebasing a shared checkout. The new reconcile pass is the catch-up path: a non-fast-forward-rejected push stays a local commit and is re-driven on the next apply. The always-on post-merge `main` run remains the backstop.

## Clean

- No command/argument injection (fixed `["git", *args]` argv, `--` separators, no shell); no path traversal (`_slug_key` + the `.`/`..` guard contain it); push only ever targets the durable branch, non-forced. *(security)*
- Test isolation solid — per-test tempdir repo+bare-origin, no shared state, no `git stash`. *(test)*
