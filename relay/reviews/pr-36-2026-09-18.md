## Reported, not changed (accepted risk)

| Finding | Why left |
|---|---|
| 🟡 Resolver executes the first PATH/glob match with no integrity check (security). | Not exploitable here — the memory dir and plugin cache are user-owned 0755, and anyone who can write them can hijack `node`/`python3`/`git` directly. The `sort -V`→`sort` change addresses the practical "which match" concern; a path-under-known-root assertion is deferred as hardening. |
| 🟢 Read path follows symlinks (security). | Precondition is write access to the user-owned memory dir; realistic blast radius is low and a symlinked `MEMORY.md` is not a Relay-created shape. Deferred. |
| Case-insensitive-FS edge: a `Foo.md` pointer vs on-disk `foo.md` drops+re-appends, replacing a curated hook (security note). | Memory slugs are consistently lowercase-kebab by convention, so latent; a correct fix needs platform-aware case handling. Deferred, noted. |
