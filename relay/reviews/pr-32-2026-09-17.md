# Review — PR #32 · read-side resume_delta validation (slice 2)

Fan-out: security, backend, test-engineer. **No blockers.** Backend confirmed correctness on all
paths; the two 🟡 and the fixed 🟢 are quality/observability improvements. All applied; suite green
at 34 tests.

## 🟡 Should-fix (resolved)

- [x] **`discover_active` `except Exception` too broad** — `scripts/relay_harvest.py`. Raised by **security** (🟡) and **backend** (🟢), converging. Once `_checkpoint_resume_delta`'s `isinstance` guard makes the helper HarvestError-only, a broad `except` would mask a real programming bug as "all checkpoints invalid." **Fix:** narrowed to `except HarvestError` — a contract violation degrades, a genuine bug still surfaces. (Reconciles with the challenger's earlier "don't scope to HarvestError only", which assumed no isinstance guard; the guard is what makes narrow both correct and safe.)
- [x] **error message unverified** — `scripts/tests/test_relay_harvest.py`. Tests asserted only the exception *type*, not the "regenerate the handover" contract. **Fix:** `assertRaisesRegex(rh.HarvestError, "regenerate the handover")` on the present-null case.
- [x] **no read-path test for empty `{}` delta** — an over-strict regression in `_checkpoint_resume_delta` would go undetected. **Fix:** added a `resume_context` assertion that an empty delta resumes (returns `{}`) rather than raising.

## 🟢 Nits

- [x] **unparseable-on-disk checkpoint read as "absent", not "invalid"** — backend. A present-but-corrupt-JSON file returned `cp is None`, so it looked like "no checkpoint" rather than "regenerate me" — undercutting slice 2's whole point. **Fix:** `discover_active` now uses `os.path.exists` to set `has_checkpoint`, and marks a present-but-unparseable file `checkpoint_status: "invalid"`. New test `test_discover_flags_unparseable_checkpoint`.
- [ ] **`cp == {}` labelled differently by the two readers** — backend. A hand-edited empty-object checkpoint is `invalid` in discover but "no durable checkpoint" in resume_context. **Won't fix:** both paths fail safely; only the message differs, and an empty-object checkpoint is a degenerate hand-edit, not a shape the runtime writes.
